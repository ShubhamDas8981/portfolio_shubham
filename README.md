# Shubham Das — Portfolio

A responsive, single-page HTML portfolio designed for GitHub Pages.

## Deploy to GitHub Pages

1. Extract this folder.
2. Open your repository: https://github.com/ShubhamDas8981/portfolio_shubham
3. Upload `index.html`, `Shubham_Das_Resume.pdf`, `shubham-das-portrait.png`, and `ganesh-ji-artwork.png` to the repository root (same level as README).
4. Commit to the branch configured for GitHub Pages (usually `main`).
5. In Settings → Pages, select Deploy from a branch → `main` → `/ (root)` if not already configured.
6. Visit https://shubhamdas8981.github.io/portfolio_shubham/

No build step, Node.js, framework or backend is required.

## Before publishing

- Confirm the live project URLs are still active.
- Add a professional headshot only if you want one; the design intentionally uses an abstract graphic instead of inventing a portrait.
- Verify the phone number and contact details in the résumé PDF.
